## 近满上下文压力

使用原生 token 数组输入，禁用 prompt cache，输入为合成 token 序列，不包含赛事答案。
记录原服务报告的实际 token 数，而不是字符估计；两次都生成 16 token、无截断、cache_n=0。

| 输入 token | 实际处理 | 生成 token | 墙钟 | 设备显存峰值 |
| ---: | ---: | ---: | ---: | ---: |
| 32768 | 32768 | 16 | 52.893s | 28.217728GiB |
| 262080 | 262080 | 16 | 1249.161s | 28.222519GiB |

两项均完成且小于 32GiB。262080 距 262144 上限留 64 token 空间；它证明近窗口容量，
不证明满长输出（65535 token）稳定性或短题时限内可完成。最大输入一项约 20 分 49 秒，
应与实际 deadline_s 分开看。本轮直接测试后端，Agent 仍有 65536 字符请求限制。
期间有软件恢复及独立 EDA 探针，不把时长当作独占性能基准。

## 网络隔离：通过了什么，没通过什么

`unshare -n` 与 `unshare -Urn` 均被平台拒绝，未取得独立网络命名空间。
内核实际提供 Landlock ABI 4，因此补做内核 TCP connect 端口白名单验收，失败不会退回无约束执行。

- 只保留模型 8000、许可 2100/2101 等测试所需端口；环境移除 HTTP/HTTPS/ALL_PROXY。
- 对 loopback 未列出端口和外部地址的 80/443 连接，实际返回 EACCES。
- 真实观测许可服务同时使用 2100、2101，不能只保留 2100。
- 第一轮 XSim 被阻断并报 PrivateChannel socket 错误。XSim 还需要随机本机 TCP 通道，
  显式放行系统临时范围 32768–60999 后，真实编译/展开、3 项断言仿真、lint、综合全部通过。
- 同策略下独立 API 实际调用本地模型：Baseline 返回代码约 4.02s，Agent 约 56.04s。
  Agent 产物又经真实编译、两项功能断言仿真、lint 与综合通过；不只检查文本非空。
- 限制实际继承到 fork/exec 子进程，Linux 实测回归通过。

**这仍不能标记成完整断网/完整 IP 隔离通过。** ABI 4 只按 TCP 端口限制，
不限制目的 IP，也不覆盖 UDP；给 XSim 放行的临时范围对所有目的 IP 有效。
完整要求仍需要平台侧的网络命名空间或按地址区分 loopback、内部许可/DNS与外网的 ACL。
当前证明的是指定 TCP 限制下的实际运行和常见下载端口拒绝。
依据：[Linux 6.8 Landlock 网络规则](https://www.kernel.org/doc/html/v6.8/userspace-api/landlock.html)。

`tools/tcp_sandbox.py` 是可信验收工具，不加入模型可调用工具表，也不默认改变生产服务网络策略。
